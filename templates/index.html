Frequently asked questions.

What is UniDraft AI?

UniDraft AI is an academic document formatting system designed to help students format their reports using a college reference document.

Which file formats can I upload?

The current version supports PDF and DOCX files.

Will my original content be changed?

The goal is to preserve your original ideas and information while applying the required document formatting.

Does it work with scanned PDFs?

Scanned PDF support requires OCR functionality, which can be added in a later development stage.
